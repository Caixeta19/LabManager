# LabManager 🧪

Sistema de Gestão de Laboratórios desenvolvido para automatizar e facilitar a reserva de espaços, controle de equipamentos, gerenciamento de empréstimos, realização de check-in e validação via QR Code.

## 🚀 Tecnologias e Ferramentas

Este projeto foi construído utilizando o ecossistema Spring e diversas bibliotecas modernas:

* **Java 17**
* **Spring Boot 3.3.4**
* **PostgreSQL** (Banco de dados principal)
* **Spring Data JPA & Hibernate** (Persistência de dados e mapeamento relacional)
* **Spring Security** (Autenticação e controle de acesso)
* **Spring Validation** (Validação de DTOs)
* **Flyway** (Versionamento e migração do esquema do banco de dados)
* **ZXing** (Geração e leitura de QR Codes)
* **Springdoc OpenAPI / Swagger** (Documentação interativa da API)
* **Lombok** (Redução de código boilerplate)
* **Maven** (Gerenciador de dependências)

## 📋 Pré-requisitos

Antes de baixar e executar o projeto, você precisará ter instalado em sua máquina:
* [Java JDK 17](https://jdk.java.net/17/)
* [Maven](https://maven.apache.org/)
* [PostgreSQL](https://www.postgresql.org/)
